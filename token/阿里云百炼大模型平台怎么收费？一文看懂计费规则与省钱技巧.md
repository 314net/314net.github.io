## 一、百炼平台三大计费项目

百炼的收费主要围绕模型全生命周期展开，分为 **模型推理（调用）、模型训练（调优）、模型部署** 三项：

### 1. 模型推理费用（最常用）

这是绝大多数用户会接触到的计费项。简单说，就是你每次调用大模型 API 时产生的费用。

**计费公式：**

```
推理费用 = 输入 Token 数 × 输入单价 + 输出 Token 数 × 输出单价
```

Token 是大模型处理文本的最小单位，通常 1 个汉字约等于 1~1.5 个 Token，英文单词则视长度而定。百炼按「千 Token」为单位计费，不同模型的单价差异很大。

**主流模型参考价格（中国内地）：**

| 模型  | 输入单价（元/千 Token） | 输出单价（元/千 Token） |
| --- | --- | --- |
| qwen-turbo | 0.0003 | 0.0006 |
| qwen-plus | 0.0008 | 0.002 |
| qwen-max | 0.02 | 0.06 |
| qwen3.7-max | 0.012 | 0.036 |

> 注：价格可能随官方活动调整，以上仅供参考，以百炼控制台实时显示为准。

### 2. 模型训练费用（微调场景）

当预置模型无法满足业务需求时，你可以用自己的数据对模型进行微调（SFT）。

**计费公式：**

```
训练费用 = (训练数据 Token 数 + 混合训练数据 Token 数) × 循环次数 × 训练单价
```

训练单价最低约 **0.006 元/千 Token**。开始训练前，控制台会显示预估费用，训练完成后新模型必须部署才能调用。

### 3. 模型部署费用（独占实例）

微调后的模型或需要高并发、低延迟的业务场景，可以选择将模型部署到独占实例上。部署费用有两种计费方式：

- **按时间计费**：适合对延迟和 SLA 要求高的生产环境
- **按调用量计费**：适合快速验证训练效果

轻量版实例价格约 **20 元/小时** 起。

## 二、四种付费模式，怎么选？

百炼目前提供四种付费模式，适合不同规模和场景的用户：

### 模式一：按量付费（默认，后付费）

- **特点**：用多少付多少，无需预购
- **适合**：低频调用、临时测试、用量波动大的场景
- **缺点**：单价最高，无任何折扣

### 模式二：Token Plan（订阅套餐）

- **特点**：购买"坐席"获得固定 Credits 额度，Credits 可跨模型通用抵扣
- **价格**：标准坐席 198 元/月（含 25,000 Credits），尊享坐席 1398 元/月（含 250,000 Credits）
- **适合**：团队协作、需要多模态（文本+图像+视频）调用的场景
- **优势**：包季可叠加模型折扣，综合低至 **4.5 折**

### 模式三：Coding Plan（编程专用）

- **特点**：专为程序员设计，按调用次数计费
- **价格**：约 200 元/月，包含 9 万次调用
- **适合**：个人开发者日常写代码、本地开发调试
- **限制**：仅限本地交互式开发，禁止批量自动化脚本

### 模式四：节省计划（预付费折扣）

- **特点**：承诺 3/6/12/24 个月的月度消费金额，换取阶梯折扣
- **折扣力度**：最高可达 **5.3 折**（多模态 B 类模型），A 类模型（千问系列）最高 **6.8 折**
- **适合**：调用量稳定且较大的企业用户
- **付款方式**：支持全预付或零预付

**抵扣优先级（重要！）**：

```
免费额度 → 资源包 → 其他模型节省计划 → AI 通用型节省计划 → 按量付费
```

对于支持 Batch（批量）调用的模型，输入和输出 Token 单价仅为实时推理的 **50%**。适合非实时场景，如批量文本生成、离线数据处理等。

### 技巧 3：开启上下文缓存（Context Cache）

如果你的场景需要反复使用相同的系统提示词或背景知识（比如固定角色设定的客服机器人），可以开启上下文缓存功能。缓存命中后的输入 Token 价格大幅降低，部分模型缓存命中价低至 **1.2 元/百万 Tokens**。

### 技巧 4：错峰使用享夜间折扣

部分模型（如 qwen3.7-max）在夜间时段（22:00 - 次日 08:00）提供大幅优惠，最高可达 **2 折**。适合对实时性要求不高的离线任务调度到夜间执行。

### 技巧 5：叠加节省计划 + Token Plan

企业用户可以组合使用「Token Plan + 节省计划」，先用 Token Plan 的 Credits 抵扣，超出部分再用节省计划的折扣抵扣，实现双重降本。

### 技巧 6：选择合适的模型

不是每个任务都需要最强模型。日常问答、文本摘要用 **qwen-turbo**（ cheapest ）；复杂推理、创意写作用 **qwen-plus** 或 **qwen-max**。合理分级使用，能节省 70% 以上的成本。
