# 一文详解WorkBuddy的功能及购买订阅详细流程

## 一、WorkBuddy 是什么？

**[WorkBuddy](https://cloud.tencent.com/act/cps/redirect?redirect=6871&cps_key=8772ad93be7c9844513d6c92c2899144&from=console)** 是腾讯 CodeBuddy 团队推出的全场景 AI 办公智能体，定位为**"坐在你电脑里帮你干活的 AI 同事"**。与传统 AI 聊天工具只能"给建议"不同，WorkBuddy 的核心能力是**理解自然语言需求 → 自主拆解任务 → 调用工具执行 → 交付可直接使用的工作成果**。

简单来说，你只需用日常语言描述需求，比如"分析这个文件夹里的销售数据，生成一份 16:9 的汇报 PPT"，WorkBuddy 就能自主读取文件、分析数据、生成报告，全程无需人工干预，直接交付成品。

---

## 二、WorkBuddy 核心功能详解

### 1. 自然语言任务执行（闭环交付）

这是 WorkBuddy 区别于普通 AI 工具的最大亮点。你不需要学习复杂指令，用大白话描述任务即可。AI 会自动拆解步骤、规划执行流程，并在过程中自我校验与修正，直至完成目标。

**典型场景**：

- "整理这批文件并生成汇总报告" → 自动读取、分类、汇总、生成文档
- "把这组数据做成带趋势分析的 PPT" → 自动分析数据、生成图表、排版成 PPT

### 2. 多模态内容生成

WorkBuddy 支持生成多种格式的办公成果，覆盖职场高频需求：

| 成果类型 | 具体能力 |
| --- | --- |
| **文档** | 工作报告、会议纪要、技术文档、邮件 |
| **表格** | 数据清洗、统计分析、可视化图表 |
| **PPT** | 自动搜集素材、规划结构、排版美化 |
| **图片** | 海报设计、配图生成 |
| **代码** | 批量处理、重构、注释生成 |

### 3. 本地文件直接操作

WorkBuddy 可在用户授权的文件夹范围内，直接读取和写入本地文件，完成批量整理、分类、重命名、格式转换等操作。数据**本地执行、不出端**，兼顾效率与隐私安全。

### 4. 多 Agent 并行协作

复杂任务可拆分为多个子任务，由不同 Agent 同时处理。例如：一个 Agent 负责数据收集，一个负责分析建模，一个负责生成报告，大幅缩短整体完成时间。

### 5. 技能（Skill）扩展系统

WorkBuddy 内置超过 20 种官方技能包，涵盖周报生成、PPT 制作、数据分析、深度调研、文件整理等场景。同时支持通过 MCP 协议连接外部工具，以及安装第三方技能，类似"App Store"的扩展逻辑。

### 6. 多模型自由切换

不绑定单一模型，支持混元、DeepSeek、GLM、Kimi、MiniMax 等主流国产大模型，可按任务类型灵活切换。写文案用这个，分析数据用那个，省去"选型"烦恼。

### 7. 远程操控（Claw 功能）

通过绑定企业微信、QQ、飞书、钉钉等 IM 工具，你可以**手机发指令，电脑自动执行**。出门在外，发条消息"把桌面的季度报表整理成摘要发给我"，WorkBuddy 在电脑上跑完任务，结果直接回传手机。

### 8. 腾讯办公生态深度集成

原生连接企业微信、腾讯文档、腾讯会议、QQ 邮箱等，实现消息驱动的任务执行，减少在不同应用间反复切换的操作成本。

### 9. 安全与权限管控

- **文件夹级精细授权**：限定 AI 可访问的文件范围
- **高危操作自动拦截**：涉及删除、修改等敏感操作时，自动请求用户确认
- **沙箱安全机制**：任务在隔离环境中执行，避免误操作影响系统

### （二）企业版订阅流程

企业版分为 **SaaS 企业版（旗舰版）** 和 **专有云企业版（专享版）** 两种部署形态。

#### 1. SaaS 企业版（旗舰版）—— 适合中小团队

**定价**：¥198/人/月，**1 人起购**（门槛最低）

**购买步骤**：

1. 登录 [WorkBuddy 企业购买页]([WorkBuddy](https://cloud.tencent.com/act/cps/redirect?redirect=6871&cps_key=8772ad93be7c9844513d6c92c2899144&from=console))
2. 选择需购买的席位（许可证）数量，1 人起购
3. 设置超级管理员手机号（将作为发货依据）
4. 选择或创建企业（使用腾讯统一身份作为成员管理平台）
5. 选择购买时长（按月或按年订阅）
6. 勾选服务条款，点击"立即购买"确认订单
7. 完成支付，权益即时生效

> ⚠️ **注意**：若下单席位数量小于企业已授权数量，购买后将回收所有已授权席位，需重新分配。

#### 2. 专有云企业版（专享版）—— 适合大型企业

**定价**：按企业级规模起购，100 人起购

**购买步骤**：

1. 登录购买页，发起企业专享版新购

5. 勾选服务条款，点击"立即购买"

> ⚠️ **注意**：若未实名认证，需先按指引完成实名认证。

1. 登录企业后台：`https://<企业id>.copilot.qq.com/admin/usage/subscription`

## 五、总结

WorkBuddy 的核心价值在于**"从回答问题到直接完成工作"**。它不是一个聊天框，而是一个能真正操作你的电脑、处理你的文件、交付可用成果的 AI 同事。

**适合谁用？**

- 频繁处理文档、表格、PPT 的职场人
- 需要批量整理文件、自动化重复工作的效率党
- 希望利用 AI 提升团队协作效率的中小企业
- 深度依赖腾讯办公生态（企业微信、腾讯文档等）的用户

**不适合谁用？**

- 纯代码开发场景（建议用 Cursor、Claude Code 等专业工具）
- 只需要简单问答、不需要文件操作的用户

如果你正被繁琐的办公任务困扰，不妨从免费体验版开始，亲自感受这位"AI 同事"的办公效率。
