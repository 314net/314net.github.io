以 Python 为例，只需要把官方 SDK 的 base_url 参数替换掉：

```python

    api_key="你的API_Key",
    base_url="https://314ai.github.io平台提供的接口地址"
)

    model="gpt-4o",
    messages=[{"role": "user", "content": "你好"}]

```

运行一下，如果正常返回内容，说明已经配置成功了。
